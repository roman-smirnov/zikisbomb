# Asset attribution

| Item | Provenance |
| --- | --- |
| Garden world and axis rails | Adapted from the local Ziki project’s original procedural scene builders. The static meadow, bed, greenhouse, cottage, flowers and fence are drawn in Babylon.js. |
| Soil and Ziki | Original art reused from the local Ziki project. Authoring sources are included in `art/`. The soil texture uses Python’s standard library; Ziki’s GLB is exported by Blender. |
| Shady and countdown module | Original procedural geometry in `src/actors.ts`. The user’s Shady reference informed the outline and face. |
| Static garden view | A capture of the adaptation’s own Babylon scene. |
| Sound | Original cues synthesized with Web Audio in `src/audio.ts`. |
| Nunito and JetBrains Mono | Bundled with Fontsource, both under the SIL Open Font License 1.1. |
| Babylon.js | Core and glTF loader under Apache 2.0. |

The production build writes the relevant package licenses and Babylon notice to `dist/THIRD_PARTY_NOTICES.txt`.
